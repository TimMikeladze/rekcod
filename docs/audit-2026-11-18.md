# Audit 2026-11-18

Audit of `930caa5` (fleet, edge, storage, TLS, sandboxes, runtime, host ops, dashboard, CI and guest, docs). 237 findings after verification: 12 finder passes, each checked by a verifier pass. Nothing was refuted; FA-12, FD-12 and FD-22 are plausible, not reproduced. Finding detail (trigger, evidence, fix, regression test) lives in the finder reports, not here.

Two branches fix them, split by the file each finding lives in so they rarely touch the same hunk:

- `audit-fixes`: fleet, controller, edge, TLS, storage, snapshots (`fleet.rs`, `tls.rs`, `edge/`, `s3.rs`, `snap.rs`, `storage*.rs`, the node and auth side of `sandbox_api.rs`).
- `audit-fixes-host`: sandboxes, VM runtime, host ops, menu bar, dashboard, guest, CI, packaging (`sandbox.rs`, `daemon.rs`, `vm.rs`, `netstack.rs`, `dns.rs`, `proxy.rs`, `host.rs`, `server.rs`, `service.rs`, `actions.rs`, `menubar.rs`, `state.rs`, `dashboard/`, `guest/`, `.github/`, `scripts/`).

Neither branch pushes, touches the running VM, or re-signs `target/release/rekcod`. Whichever finishes second merges both and runs the full suite.
