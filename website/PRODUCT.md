# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose

The website introduces rekcod, an open source Docker Desktop alternative for Apple
Silicon Macs, and presents its repository documentation.

## Users

Developers installing rekcod or looking up a command or feature. This audience is
inferred from the existing README and guides.

## Constraints

All product content comes from repository Markdown. No copied marketing text,
invented measurements or separate content store. The user requested a super minimal
design and deployment to Vercel. Website controls may have their own interface labels.

## Brand commitments

The logo is the Docker whale rotated 180 degrees, rendered black on white, as
explicitly requested. Use the same asset in the header and favicon. The app bar
shows the logo without the product name.

## Stack

Implementation choice: Astro, Bun and static HTML. The existing dashboard remains a
separate app. No website backend is needed.
